\# Project Types  

Rust Projects • Python Projects • Hybrid Projects • Mixed-Language Projects



Project Types define how DevAiCoreX engines, workspaces, and build systems behave based on the type of project being created.



\---



\# 1. Purpose of Project Types



Project types provide:



\- engine selection

\- workspace selection

\- build system selection

\- metadata configuration

\- safety configuration



Project types ensure correct subsystem behavior.



\---



\# 2. Rust Projects



Rust projects use:



\- Rust engines

\- Cargo workspaces

\- Rust toolchains

\- Rust build systems



Rust projects follow Rust-first rules.



\---



\# 3. Python Projects



Python projects use:



\- Python engines

\- Venv workspaces

\- Python toolchains

\- Python build systems



Python projects follow Python-first rules.



\---



\# 4. Hybrid Projects



Hybrid projects use:



\- mixed engines

\- hybrid workspaces

\- Rust + Python toolchains

\- combined build systems



Hybrid projects support bindings and multi-language builds.



\---



\# 5. Mixed-Language Projects



Mixed-language projects use:



\- multi-engine setups

\- multi-workspace setups

\- multi-toolchain builds



Mixed-language projects support advanced architectures.



\---



\# 6. Summary



Project Types define how DevAiCoreX engines, workspaces, and build systems behave. They ensure correct subsystem selection and safe project creation.
