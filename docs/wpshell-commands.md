\# WPShell Commands  

Workspace Commands • Build Commands • Engine Commands • Safety Commands



WPShell provides workspace-level command-line tools for managing DevAiCoreX projects. It focuses on workspace operations, build execution, metadata inspection, and safety validation.



\---



\# 1. Purpose of WPShell Commands



WPShell commands provide:



\- workspace management

\- build execution

\- metadata inspection

\- safety validation

\- engine/workspace integration



WPShell ensures predictable workspace behavior.
