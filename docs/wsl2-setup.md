\# WSL2 Setup  

WSL2 Installation • Toolchain Setup • Engine Compatibility • Workspace Integration



WSL2 Setup defines how DevAiCoreX configures Windows Subsystem for Linux 2 for engines, workspaces, and build systems that require Linux environments.



\---



\# 1. Purpose of WSL2 Setup



WSL2 provides:



\- Linux-based toolchains

\- Linux-based compilers

\- Linux-based build systems

\- cross-platform compatibility

\- GPU passthrough support

\- container support



WSL2 ensures engines can run Linux-native operations.



\---



\# 2. WSL2 Requirements



WSL2 requires:



\- Windows 10/11

\- Virtualization enabled

\- WSL2 feature enabled

\- Linux distribution installed

\- updated kernel



These requirements ensure compatibility.



\---



\# 3. WSL2 Installation Steps



Installation steps include:



\- enabling WSL2

\- installing a Linux distribution

\- updating the kernel

\- configuring toolchains

\- validating engine compatibility



WSL2 must be configured before engine usage.



\---



\# 4. WSL2 Toolchain Setup



Toolchain setup includes:



\- Rust toolchain

\- Python toolchain

\- C/C++ toolchain

\- hybrid toolchains



Toolchains ensure engines can compile code.



\---



\# 5. WSL2 Workspace Integration



Workspace integration includes:



\- mapping Windows directories

\- mapping Linux directories

\- validating workspace structure

\- validating build paths



Integration ensures consistent workspace behavior.



\---



\# 6. Summary



WSL2 Setup provides Linux-based environments
