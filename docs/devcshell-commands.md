\# DevCShell Commands  

Creation Commands • Engine Commands • Workspace Commands • Build Commands



DevCShell provides command-line tools for creating, managing, and analyzing DevAiCoreX projects. Commands ensure consistent engine, workspace, and build behavior.



\---



\# 1. Purpose of DevCShell Commands



DevCShell commands provide:



\- project creation

\- engine selection

\- workspace selection

\- build system configuration

\- metadata inspection

\- safety validation

\- lineage inspection



Commands ensure predictable project management.



\---



\# 2. Creation Commands



create <project>

create rust

create python

create hybrid

create cargo

create venv



Creation commands initialize new projects.



\---



\# 3. Engine Commands



engine info

engine list

engine reload

engine validate



Engine commands manage engine behavior.



\---



\# 4. Workspace Commands



workspace info

workspace list

workspace reload

workspace validate



Workspace commands manage workspace behavior.



\---



\# 5. Build Commands



build run

build debug

build validate

build flags



Build commands manage compilation and debugging.



\---



\# 6. Metadata Commands



meta engine

meta workspace

meta build

meta lineage



Metadata commands inspect project metadata.



\---



\# 7. Safety Commands



safety check

safety validate

safety rules



Safety commands enforce project protection.



\---



\# 8. Summary



DevCShell Commands provide structured tools for managing DevAiCoreX projects. Commands ensure consistent, safe, and predictable project behavior.
