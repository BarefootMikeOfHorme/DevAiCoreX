\# Prompt System  

Prompt Templates • Prompt Metadata • Prompt Rules • Prompt Context



The Prompt System defines how DevAiCoreX AI agents generate content using structured templates, metadata, and safety rules. Prompts ensure consistent, safe, and engine-aware generation.



\---



\# 1. Purpose of the Prompt System



The Prompt System provides:



\- structured generation templates

\- engine-aware prompts

\- workspace-aware prompts

\- build-aware prompts

\- safety-aware prompts

\- lineage-aware prompts

\- profile-aware prompts



Prompts define how AI agents generate content.



\---



\# 2. Prompt Structure



Prompts are stored in:



ai-context/prompts/<engine>/<topic>.md



Prompts include:



\- generation templates

\- safety instructions

\- engine rules

\- workspace rules

\- build rules

\- lineage rules

\- memory rules



\---



\# 3. Prompt Metadata



Prompt metadata includes:



\- prompt type

\- prompt version

\- engine compatibility

\- workspace compatibility

\- build compatibility

\- safety level

\- profile compatibility



Metadata defines prompt behavior.



\---



\# 4. Prompt Rules



Prompt rules define:



\- allowed generation zones

\- allowed file types

\- allowed operations

\- restricted operations

\- safety overrides



Prompt rules ensure safe generation.



\---



\# 5. Prompt Context



Prompt context includes:



\- engine metadata

\- workspace metadata

\- build metadata

\- lineage metadata

\- safety metadata

\- profile metadata



Context is merged before prompt execution.



\---



\# 6. Summary



The Prompt System defines how DevAiCoreX AI agents generate content using structured templates and metadata. Prompts ensure safe, predictable, and engine-aware generation.
