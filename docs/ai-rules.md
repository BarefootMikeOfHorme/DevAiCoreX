\# AI Rules System  

Generation Rules • Safety Rules • Engine Constraints • Workspace Constraints • Build Constraints



The AI Rules System defines the complete set of rules that all AI agents must follow during project creation, modification, analysis, and generation inside DevAiCoreX. These rules ensure safe, predictable, engine-aware, workspace-aware, and build-aware behavior.



\---



\# 1. Purpose of the AI Rules System



AI Rules provide:



\- strict generation constraints

\- safety enforcement

\- engine compatibility rules

\- workspace compatibility rules

\- build compatibility rules

\- lineage enforcement rules

\- memory usage rules

\- prompt usage rules



AI Rules prevent unsafe or inconsistent generation.



\---



\# 2. Categories of AI Rules



AI Rules are divided into:



\- Generation Rules

\- Safety Rules

\- Engine Rules

\- Workspace Rules

\- Build Rules

\- Lineage Rules

\- Memory Rules

\- Prompt Rules



Each category contributes to the final rule set applied to AI agents.



\---



\# 3. Generation Rules



Generation rules define how AI agents produce content.



Generation rules include:



\- follow engine templates

\- follow workspace structure

\- follow build system requirements

\- follow prompt templates

\- follow profile constraints

\- avoid destructive operations

\- avoid overwriting protected files

\- avoid generating outside allowed directories



Generation rules ensure predictable output.



\---



\# 4. Safety Rules



Safety rules define what AI agents are forbidden from doing.



Safety rules include:



\- no execution of unsafe commands

\- no modification of restricted files

\- no deletion of project metadata

\- no bypassing safety layers

\- no generation of harmful content

\- no modification of lineage history

\- no unauthorized memory operations



Safety rules override all other rule categories.



\---



\# 5. Engine Rules



Engine rules ensure compatibility with the selected engine.



Engine rules include:



\- use engine-specific templates

\- use engine-specific build logic

\- use engine-specific debug logic

\- follow engine metadata

\- follow engine safety rules

\- follow engine version constraints



Engine rules prevent cross-engine conflicts.



\---



\# 6. Workspace Rules



Workspace rules ensure compatibility with the selected workspace type.



Workspace rules include:



\- follow workspace folder structure

\- follow workspace metadata

\- follow workspace safety rules

\- generate files only in allowed directories

\- avoid modifying workspace metadata files

\- avoid generating outside workspace boundaries



Workspace rules ensure predictable project layout.



\---



\# 7. Build Rules



Build rules ensure compatibility with the build system.



Build rules include:



\- follow build.json metadata

\- follow compiler version constraints

\- follow toolchain version constraints

\- follow build flags

\- follow safety flags

\- avoid generating invalid build configurations



Build rules ensure the project can be compiled safely.



\---



\# 8. Lineage Rules



Lineage rules ensure all generation is tracked.



Lineage rules include:



\- record all generated files

\- record all modified files

\- record engine usage

\- record workspace usage

\- record build system usage

\- record safety rule enforcement

\- append-only lineage updates



Lineage rules ensure full project history.



\---



\# 9. Memory Rules



Memory rules define how AI agents may use contextual memory.



Memory rules include:



\- no storing sensitive data

\- no storing user secrets

\- no storing destructive instructions

\- no storing unsafe patterns

\- store only allowed metadata

\- store only allowed project context



Memory rules prevent unsafe memory usage.



\---



\# 10. Prompt Rules



Prompt rules define how AI agents use prompt templates.



Prompt rules include:



\- follow engine prompt templates

\- follow workspace prompt templates

\- follow safety prompt templates

\- follow profile prompt templates

\- follow lineage prompt templates

\- avoid generating outside prompt boundaries



Prompt rules ensure consistent generation behavior.



\---



\# 11. Rule Application Flow



1\. Load AI Context

2\. Load Safety Rules

3\. Load Engine Rules

4\. Load Workspace Rules

5\. Load Build Rules

6\. Load Lineage Rules

7\. Load Memory Rules

8\. Load Prompt Rules

9\. Merge all rule categories

10\. Apply safety overrides

11\. Apply engine/workspace/build constraints

12\. Apply lineage enforcement

13\. Begin generation



This ensures safe, predictable, rule-driven generation.



\---



\# 12. Summary



The AI Rules System defines the complete rule set that governs all AI operations inside DevAiCoreX. It ensures safe, predictable, engine-aware, workspace-aware, build-aware, and lineage-aware generation across all project types.
