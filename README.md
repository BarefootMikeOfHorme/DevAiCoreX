# DevAiCoreX — Dual‑Mode AI‑Augmented Development Architecture

DevAiCoreX is a dual‑mode, AI‑assisted development environment designed for
high‑performance, multi‑language creation workflows across Windows and WSL2.

It provides two operational modes:

1. **wpshell (Normal Mode)**  
   Lightweight, stable, cross‑platform development shell for everyday work.

2. **DevCShell (Creation Station Mode)**  
   Hardened, VS2022‑integrated creation environment for multi‑language,
   multi‑engine, AI‑aware project generation.

## Core Concepts

- Windows Terminal as the unified gateway
- VS2022 as the hardened IDE hub
- WSL2 (Ubuntu, Kali, Athena) as compute engines
- Modular creation engines (C, C++, Rust, Python, PyO3, AI, GPU)
- Multi‑language workspaces
- Game engine creation environments (Unreal, Unity, Godot, CryEngine)
- Monitoring stack (btop, bottom, glances + Grafana, Prometheus, Netdata)
- AI‑context rules, prompts, memory, lineage

DevAiCoreX is designed for both human developers and AI agents, providing a
structured, predictable, and extensible environment for complex creation tasks.
