# DevAiCoreX CLI — Theme System (Enhanced)

Themes define color output for human-friendly CLI interaction.

## Default Theme

header: Cyan  
success: Green  
warning: Yellow  
error: Red  
info: Gray  
command: Magenta  

## Behavior

Themes apply to:
- status output
- build output
- error output
- routing output
- help output

Themes do NOT affect JSON output.

## Customization

Themes can be changed dynamically:

Set-DevAiTheme header Blue  
Set-DevAiTheme error Red  
Set-DevAiTheme command Magenta  

## Purpose

Improve readability, accessibility, and user experience across all CLI interactions.
