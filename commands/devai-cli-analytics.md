# DevAiCoreX CLI — Analytics System (Enhanced)

Analytics track local command usage to improve debugging and user experience.

## Tracked Data
- Command usage count
- Subcommand usage count
- Engine/workspace/AI/game usage
- Shell mode usage
- Creation Station usage

## Storage
analytics.json (local only)

## Behavior
- Updated automatically when commands execute
- Never transmitted externally
- Used for performance tuning and diagnostics

## Purpose
Improve CLI optimization, routing accuracy, and developer insight.
